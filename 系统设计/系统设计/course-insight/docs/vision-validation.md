# 真人视觉与多端课堂验收

## 三层证据

1. 接口回归验证权限、写入、同步、归档与异常路径；测试 JSON 不是识别效果证据。
2. 视觉实验室输入真实录像或主动开启的真人摄像头。模型、WASM、举手/闭眼逐帧判据与课堂共用，报告保存预测、标签、混淆矩阵、覆盖率与耗时。
3. 真人多设备课堂验证设备权限、浏览器前后台、网络中断、屏幕撤销和实际采样性能。回放不能代替这一层。

## 无需虚拟学生摄像头的测试方法

打开 /vision-lab.html，选择已获同意录制的 MP4/WebM。录像由浏览器本地解码，不上传课堂。可另选包含 intervals 数组的 JSON 标签，再点击“运行视频回放”。模型实际处理每 0.25 秒对应的视频帧，导出的报告可重复比对。

标注例子见本目录 vision-labels.example.json。将示例时间和状态改成自己录像的真实内容，不能直接把示例当作真值。时间区间左闭右开且不能重叠；未标注信号省略。

报告区分三项：facePresent（存在人脸）、handRaised（腕高于肩）、eyesClosed（双眼闭合程度均大于 0.5）。这不是身份识别，没有人脸注册、身份模板或核验逻辑，签到依赖登录账号。

模型没有足够关键点时为不可判定。覆盖率 = 可判定的已标注帧 / 所有已标注帧；精确率、召回率只基于可判定帧，必须连同 unknown 和覆盖率阅读。标签不足或分母为零显示空值，不把它当成 100%。连续视频帧高度相关，不能把帧数当独立受试人数。

## 采样与验收集建议

| 样本组 | 需要录制的变化 | 核查重点 |
| --- | --- | --- |
| 正脸与离开 | 正常入座、短暂离开、空座、回座 | 人脸存在的漏检、空座误检 |
| 光照与姿态 | 明亮、低光、逆光、侧脸、低头 | 分组覆盖率与误报，不只看总体均值 |
| 眼镜与遮挡 | 普通眼镜、反光、口罩、手遮脸 | 不可判定是否被错误计为正常 |
| 举手 | 左右手、双手、半举、触碰头发、放下 | 手腕/肩部可见性与反例误报 |
| 闭眼 | 正常眨眼、眯眼、单眼、持续闭眼 | 短暂眨眼不能等同持续闭眼或睡觉 |
| 多设备 | 不同摄像头、分辨率、CPU/GPU、浏览器 | 平均/P95 检测耗时、卡顿和模型启动 |

先以 5–10 位愿意参与者的小规模样本发现问题，之后扩充独立验收集；这只是试验规模建议，不代表统计充分。每段包含正负例、记录设备与场景；另一标注者复核边界。按人或设备划分调参集与验收集，避免同一视频相邻帧同时用于调参与最终验收。验收阈值由实际场景确定，不预先承诺准确率。

正式课堂本地识别每次完成后约 500 ms 再采样，网络约 4 秒上报；硬件耗时会延长采样间隔。课堂对举手使用 1.5 秒、闭眼使用 3 秒持续阈值。实验室当前输出逐帧指标，仍需真人课堂核查持续动作延迟及后台恢复；闭眼不能证明睡眠。

## 多端验收操作

1. 教师电脑、学生电脑/手机使用独立账号。相同用户名不可重复注册；同名不同账号应独立。
2. 两位教师同时开课，互看历史列表、资料库、导出及共享入口；不得串数据。学生分别凭对应课堂码加入。
3. 学生开启摄像头，观察本地预览和教师信号；关闭、拒绝权限、拔除设备后不能保留旧识别结果。
4. 学生切换浏览器标签页后返回，核查切到后台次数；单纯失焦单独计数。浏览器允许的范围只涉及该网页，不能获知其他应用内容。内嵌浏览器的可见性行为可能与桌面浏览器不同，应以 Chrome/Edge 真机验收。
5. 教师发起签到，学生重复点击只产生一条响应；过期/教师结束后不能补签。教师关评论、置顶、隐藏与恢复，学生端应同步。
6. 学生点击“共享我的屏幕”，在浏览器选择窗口或屏幕。教师选择该学生查看；学生停止、退出、换课、断联或教师结课后画面必须撤下。
7. 断开网络、恢复网络、刷新、退出重登和服务重启；核查错误提示与账号持久化。页面活动发送失败会提示未同步，离线丢失的事件不能推定为零次切屏。
8. 结束课堂，检查签到、活动、评论、反馈、教学结论与导出一致。

跨设备访问需要局域网可达地址；摄像头/屏幕要求安全上下文，使用 HTTPS，localhost 仅适用于当前设备。学生屏幕当前为约 1 FPS JPEG，适合低频查看；不是远程控制或视频会议，也没有系统音频。
