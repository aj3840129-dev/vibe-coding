# 需求说明

## 项目名称

智课云舱：AI 驱动的线上课堂学情监测系统。

## 真实需求

线上课堂和混合课堂中，教师面对的难点不是“能不能开课”，而是：

- 教师看不见学生是否真的在听。
- 学生疑惑、疲劳、离开等状态很难被及时发现。
- 摄像头、门口传感器、课堂反馈等数据彼此割裂。
- 课堂结束后缺少可解释的数据报告。
- 学生提问容易脱离课程资料，答案缺少依据来源。

本系统的目标是把课堂采集、实时同步、知识问答、智能分析和风险预测整合成一个可演示、可解释的 Web 系统。

## 用户角色

- 学生：加入课堂、开启摄像头、提交反馈、基于课程资料提问。
- 教师：查看实时课堂状态、教室人数、异常提醒、风险学生队列、AI 学情报告。
- 管理员：维护教室、课程资料、设备来源和系统配置。

## 核心功能

- 教师实时驾驶舱。
- 学生端摄像头状态上报。
- 门口传感器进入 / 离开事件。
- 多教室人数统计与异常偏差提醒。
- RAG 课程资料问答。
- AI 学情诊断报告。
- 低参与风险预测。
- SSE 实时数据流。

## 非功能需求

- 现场演示必须稳定。
- 摄像头不可用时必须有备用演示路径。
- 所有关键数据需要进入后端保存。
- 每个特色技术都要能解释其业务价值。
