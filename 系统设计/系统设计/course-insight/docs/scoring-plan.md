# 满分评分路线

## 85 分基础

- 有 2 个以上主要功能区域：教师驾驶舱、学生摄像头节点、传感器节点、RAG 问答、AI 报告。
- 有 3 个以上 API：状态、SSE、学生状态、传感器事件、RAG 问答、AI 分析。
- 有数据存储：课堂状态、事件、问答、报告保存到后端。
- 页面展示后端返回数据。
- README 说明如何运行和演示。

## 90 分标准项目

- 前后端分离。
- 多类数据对象：Room、Student、SensorEvent、KnowledgeDoc、AIReport。
- 动态数据可视化：人数、专注率、风险分、教室异常。
- 数据闭环：前端采集 / 模拟 -> 后端保存 -> 实时推送 -> 前端展示。

## 95 分特色技术深度

主特色技术：真实硬件控制与终端能力调用。

- 浏览器真实调用摄像头。
- 视频帧提取基础特征。
- 识别结果进入后端。
- 教师端实时展示学生状态。
- 传感器事件影响教室人数。

第二特色技术：实时数据流。

- 使用 SSE。
- 至少两个窗口可以看到同步效果。
- 摄像头、传感器、反馈、AI 报告都能触发推送。

第三特色技术：RAG 与 AI 学情分析。

- 问答基于课程资料片段。
- 展示依据来源。
- 生成的 AI 报告影响教师端决策。

## 100 分冲刺点

- 把五个技术点讲成一个业务闭环。
- 现场演示有主路径和备用路径。
- 明确说明数据来源、更新机制和异常处理。
- 展示 AI 报告如何改变教师决策。
- 展示项目不足和后续优化方向。
