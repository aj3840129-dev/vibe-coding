## 每次提交前

在应用目录执行：

~~~sh
npm run check
npm run release:check
npm test
~~~

测试使用临时数据目录和随机回环端口。不得用用户数据库作为测试夹具。摄像头配置、密码、SQLite、旧 store 文件与 .runtime 均不得提交。release:check 检查 Git 索引，因此新增文件必须暂存后再检查一次。

GitHub Actions 在 Windows 与 Ubuntu、Node 24 上运行同一套检查并保存测试日志。推送成功不等于云端检查成功，应以 Actions 实际结果为准。

## 发布与回滚

通过真实设备与多人场景验收后，以 PR 将 develop 合入 main；填写变更、数据兼容性、测试证据与未验收项，发布对应版本。当前 package 版本为 0.4.0，不代表学校实机验收完成。

部署前停止应用并备份完整 DATA_DIR。回滚按代码版本和数据备份成对恢复；不删除新版本数据。公开仓库过去上传的数据库即使停止跟踪仍留在旧提交中，应另行安排凭据轮换、影响评估与历史清理；本次不进行强制推送或历史重写。
