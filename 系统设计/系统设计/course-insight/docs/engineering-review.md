# 工程评估与改进记录

评估日期：2026-09-07，版本 0.3.0。以当前代码和本轮验证为准。

## 本次三个问题的处理

| 用户问题 | 当前实现 | 验证与限制 |
| --- | --- | --- |
| 不同账号共享课堂历史 | SQLite 真实账号；username 唯一、显示名独立、scrypt 密码；课堂/资料/归档关联 teacher owner_id，SSE 和屏幕同样隔离 | 两位同名教师同时开课，跨账号历史/导出被拒绝，重启重新登录保留原账号与历史 |
| 测试都是虚拟输入 | 新增真实视频/摄像头实验室，人工区间标签、混淆矩阵、精确率/召回率/覆盖率、JSON 报告；共用正式课堂视觉判据 | 评估计算测试通过，三个本地模型在浏览器成功初始化；未有真人标注样本，不能声称识别准确率已验证 |
| 教师课堂管理不足 | 课堂管理四个页签：签到、页面活动、学生屏幕、评论；学生对应操作入口；管理数据进入复盘与导出 | 签到、评论、复盘通过双端浏览器操作；切屏/权限/屏幕中继通过接口测试，真实设备授权采集仍待验收 |

## 已集成工程

- 原生 HTML/CSS/JavaScript 六个角色视图，深蓝侧栏、浅色工作区、课堂管理页签、响应式布局与键盘导航。
- Node.js HTTP + SSE；账号会话鉴权、课堂版本验证、同一学生成员绑定与本人数据裁剪。
- SQLite accounts、workspaces、live_classes、classroom_archives、active_memberships、legacy_imports。
- 本地 MediaPipe Face Detector、PoseLandmarker、FaceLandmarker，随项目托管 JS/WASM/模型；视觉判断是人脸存在、姿态与闭眼，不是身份识别。
- 文本资料入库、切片关键词检索、引用依据、问答持久化；可选 OpenAI 兼容服务，失败时本地回退。
- 学情规则分析、教师教学回应、学生理解确认、教师跟进结论、过程趋势、结课不可变归档和 Markdown 导出。
- 课堂投票、公告、教师屏幕低帧率中继、学生主动授权共享、限时签到、评论管理、页面活动。
- 门禁模拟与教室人数协同仍保留为联调入口，没有实际硬件接入。

## 数据闭环

教师账号开课 → 学生账号加入 → 真实终端信号/主动反馈/签到/评论/提问 → 校验身份和课堂版本 → SQLite 持久化并按角色推送 → 教师分析和教学回应 → 学生确认理解 → 教师记录结论 → 结课冻结归档 → 历史回看/导出/调整下一次教学。

签到记录保存目标成员和去重响应；评论保留原文与软隐藏状态；页面事件按服务端时间记录，hidden 与 blur 分开。图片驻留内存，停止共享与超时后不继续显示。

未知视觉不再沿用旧自动举手/闭眼；手动反馈保留独立来源。视觉采样约每次完成后 500 ms，网络约 4 秒；后台和长采样间隔重新累计持续动作阈值。参与参考值、风险和闭眼提示仍为辅助规则，不能当作学习成效或睡眠真值。

## 数据迁移

旧 store.json 未删除，另在 legacy_imports 按校验和保全。旧姓名没有可信的账号归属，不自动认领旧历史。当前每个新教师账号从空课堂、空资料库开始。SQLite 内业务状态仍为教师级 JSON 快照，只有账号、课堂索引、归档和成员关系单独建表；这轮完成隔离与持久化，并未宣称所有业务已完全关系化。

## 验证记录

自动测试完整输出见 [verification/account-tools-tests.txt](verification/account-tools-tests.txt)。测试使用临时数据目录及随机端口，外部 AI 用本地模拟服务。浏览器验收使用 .runtime/account-qa，不污染用户 backend/data。

已验证网页注册、教师开课、学生加入、签到实时推送和结果、评论提交/置顶/关闭、管理复盘与学生自动离课；桌面管理面板与实验室截图已检查，无横向溢出。本轮没有实际申请用户摄像头/屏幕权限，也没有真人标注准确率与公网负载结果。上一版移动端入口验收不能代表本轮全部新增页面均已完成真机验收。

## 优先改进方向

1. 按 [真人视觉验收](vision-validation.md) 收集独立真人样本，量化误报、漏报、覆盖率和检测耗时；先有证据再调阈值。
2. HTTPS 多设备及断网/恢复验收；大班场景增加消息增量推送、节流和容量测试。
3. 若需要高帧率多人屏幕与音频，建设 WebRTC/SFU；当前 JPEG 中继只能做低频观察。
4. 账号体系补齐管理员、找回密码、学校/组织、课程授权、登录限流；公开部署时配置教师注册邀请码。
5. 将教师级快照进一步拆为独立业务表，增加迁移版本、定期备份与恢复演练；多进程部署前外置会话和媒体通道。
6. 增加课程资料版本、文件解析与检索评估；为学生提供可访问自己的跨课复盘。

当前是具备真实账号隔离、教学数据闭环和可复现视觉评估入口的课程工程，仍需真人数据与设备验收来支撑识别效果和生产容量结论。

下一步优先级：先补齐真实流路径、校园网络及 FFmpeg，完成一间教室实机验收；随后建立经同意的远景课堂标注集、分区域量化漏检与误报；有数据依据后再选专用多人模型和边缘分析服务。当前教师页面驱动的识别适用于有人操作的低频观测。部署流程与版本检查见 [development-workflow.md](development-workflow.md)，接入说明见 [campus-deployment.md](campus-deployment.md)。
