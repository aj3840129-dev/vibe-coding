# 双端验收顺序

1. 启动服务，在两个独立标签页分别进入教师和学生。
2. 教师填写课堂名称与主题并开课，展示 0 学生与未采样指标。
3. 学生手动输入课堂码加入，教师看到成员和接入教室。
4. 学生提交疑問，教师看到待关注记录。教师补充一段文本资料，学生提问并展开依据片段。
5. 教师生成学情分析，发送教学回应。学生选择仍需帮助，再确认已理解；教师记录跟进结论。
6. 发起投票并由学生作答，结束投票。模拟门禁进出并切换教室，说明摄像头、在线人数和门禁的区别。
7. 如用户主动授权，可展示摄像头与屏幕采集；没有权限时主流程仍可正常完成。
8. 结束课堂，查看真实采样曲线、结束快照与干预确认；导出复盘。
9. 返回工作台开新课，旧学生不能继续写入；历史列表仍能打开上节课复盘。

不能声称已实现多人音视频会议、接入真实门禁或训练了专注识别模型。外部问答是否使用在线模型，以实际返回方式为准。
