# v0.4.0 线下课堂部署与验收

## 已实现的接入路径

摄像头 RTSP → 本机 FFmpeg → 约 1 FPS JPEG → 鉴权 HTTP API → 教师浏览器本地 MediaPipe → 教室级观测 → SQLite → 教学调整与效果结论 → 不可变归档。

HTTP(S) JPEG 抓图端点可直接使用，不需要 FFmpeg。当前 HTTP 抓图支持 Basic 认证；只提供 Digest 认证的设备应选择 RTSP，或使用厂商确认的兼容抓图方案。RTSP 默认走 TCP，路径由厂商提供，不根据 IP 猜测。RTSP 是低帧率观测接入，没有录音、录像、PTZ 控制或多人音视频会议。

## 本地设备登记

本机七间教室（201、203、204、205、207、208、209）已登记在 backend/data/campus-cameras.json。真实地址与凭据仅在该被忽略的私有文件中，仓库只提供 config/campus-cameras.example.json 的保留地址示例。

配置字段：id、name、roomId、host（固定 IP）、protocol、port、streamPath、username、password、allowedUsernames。文件由服务器管理员维护；浏览器只能调整已获授权设备的协议、端口、路径和凭据，不能替换目标 IP。设备密码不返回 API，也不进入 FFmpeg 日志。服务器文件访问权仍需操作系统保护；本地 FFmpeg 命令行包含连接凭据，应限制服务器进程查看权限。

## 开始使用

1. 启动项目并注册教师账号。
2. 在项目目录运行：npm run campus:grant -- 教师账号。若只授权一间教室，末尾追加教室号，例如 201。
3. 教师工作台刷新“教室与设备”。展开“设备接入设置”，填写厂商提供的视频路径，并测试端口连通性。设备参数已填不等于设备在线。
4. RTSP 接入需在服务器安装 FFmpeg 并加入 PATH，或设置 FFMPEG_PATH 为 ffmpeg 可执行文件的绝对路径；之后重新启动服务。推荐从 ffmpeg.org 链接的可信构建源安装。本轮下载站连接超时，未自动安装成功。
5. 选择“线下教室”或“混合教学”，选授权教室后开课。点击“接入摄像头”。手机学生仍可通过互动码加入签到与评论。
6. 观察画面信号，记录“课堂观察 / 教学调整 / 效果结论”。效果结论必须关联一条尚未完成的教学调整。
7. 结束课堂后查看线下观测趋势、调整与结论，以及签到评论复盘。

## 连接前提与诊断

摄像头地址属于校园内网，运行 Node/FFmpeg 的服务器必须处于可达的校园网或合规 VPN 中。前端通过服务器取帧，不要求浏览器直接连接设备，也不会向学生返回校园摄像头画面。

运行 npm run campus:diagnose -- 201，只检查指定登记设备的一个配置端口及 FFmpeg 可用性，不登录设备、不遍历网段、不猜测密码。TCP 成功不能证明 RTSP 路径或凭据正确。

2026-09-07 至 09-08 本机验证：201 教室的配置端口 554 不可达，未填写经厂商确认的流路径，未找到 FFmpeg。因此学校摄像头实流尚未验收；不能写成七间教室已经在线。

## 数据口径与生命周期

- 记录可见人体、举手人体、可见人脸、画面亮度、像素变化和本地检测耗时；不做人脸身份注册、情绪推断或个人专注排名。
- 当前 PoseLandmarker 单帧上限 12 人，模型是近景预训练模型，远景教室、遮挡与高密度场景会漏检。显示的是模型可见目标，不能作为全班真实人数或自动考勤。
- 画面人数与线上账号数分别统计，不相加。不同摄像头的重叠视角不合并为总人数。
- 模型失效为不可判定；没有画面时不写入虚构样本。样本来源明确为 teacher-browser-mediapipe，客户端上报不用于高风险自动决策。
- 本轮识别依赖教师浏览器保持当前页面开启；切后台、离开课堂页、主动停止、退出或结课均停止接入。45 秒没有教师取帧自动释放设备。
- 画面超过 6 秒无更新视为过期，前端断流撤下旧图。每台设备只允许一堂课占用；同账号多标签页不作为独立监测通道。
- 原始画面只驻留内存，不保存录像。教室数值及教学记录保存在当前教师工作空间；最多保留 3600 个过程样本，超限均匀降采样。样本首末跨度不等于连续监测覆盖时长。
- 摄像头无法直接证明学生是否理解。教学效果以教师记录的课堂证据与反馈结论为准。

## 真实验收清单

- 确认设备型号、实际 RTSP/抓图路径、校园网连通性和教师账号授权。
- 单教室测试：认证失败、端口不通、错误路径、断流、恢复、切后台、结课和刷新。
- 多教室测试：不同教师只能访问获授权教室；同一设备占用冲突被明确拒绝。
- 用经同意的真人课堂样本人工标注人数与举手，按光照、座位区域、远近、遮挡计算漏检与误报；当前近景模型若不满足要求，再迭代专用多人人体检测和远景姿态模型。
- 若需要无人值守全天监测，应把分析迁移到校内边缘服务，并单独实现后台任务、恢复机制和设备容量验收。
