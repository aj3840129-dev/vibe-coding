# 系统架构（2026-09-07）

浏览器通过 REST API 提交课堂数据，SSE 推送服务端按账号、课堂与角色裁剪后的状态。单个 Node.js 进程可服务多个教师的独立课堂。

## 账号与数据边界

账号注册写入 SQLite accounts，唯一 username 与显示姓名分离，密码经随机盐 scrypt 派生。登录生成随机会话，ownerId 来自账号和 active_memberships，不接受客户端指定教师所有者。

HTTP 入口以 AsyncLocalStorage 隔离请求上下文；workflows.js 验证账号角色、课堂版本与学生成员关系。数据库 workspaces、live_classes 和 classroom_archives 强制 owner_id，课堂码全局唯一。SSE、教师屏幕与学生屏幕按 ownerId 隔离。学生只获得自己的遥测、反馈、问答、签到记录，以及当前课堂可见评论和教师授权内容。

课堂业务状态暂存为每位教师的 JSON 快照，SQLite 事务同步更新在线课堂索引与不可变归档；外部 AI 等异步调用完成后重新读取最新状态再合并。会话与图片驻留内存，因此部署仍限单进程。

## 课堂管理与闭环

classroom-tools.js 提供签到、页面活动、评论和学生授权共享。hidden 记录前台到后台转换，blur 单独统计，事件按 ID 去重并使用服务端时间。签到按账号去重，评论软隐藏保留原文。结课冻结活动时长、签到、评论、教学干预和趋势，教师历史复盘与 Markdown 导出使用同一归档。

学生 getDisplayMedia 主动授权后，每秒发送 JPEG，教师轮询查看；图片不会写数据库。停止/退出/转课/结课和 15 秒过期均限制查看。该通道没有声音，不是多人 WebRTC 会议。

## 视觉验证

正式课堂约每次检测完成后 500 ms 再采样，网络每 4 秒提交最新有效信号；后台、超过 2 秒未获得有效采样、模型缺失返回不可判定，并重置持续时间。vision-metrics.js 复用举手与闭眼判据。

vision-lab.html 在本地解码视频，每 0.25 视频秒定位一帧，调用真实 MediaPipe 模型，匹配人工区间标签并导出覆盖率和混淆矩阵。实验数据不写课堂；没有标注不生成准确率。实验室评估逐帧状态，正式课堂还包含举手 1.5 秒和持续闭眼 3 秒的时间阈值。

## 旧数据

旧 store.json 原样保留且按校验和写入 legacy_imports。旧姓名不能证明账号所有权，因此不会自动认领到新账号。store.js 只保留兼容恢复工具，在线读写以 SQLite 为准。

## v0.4.0 线下教室扩展

meeting 新增 mode 与 campusRoomId，campus 保存数值样本及教学记录。校园摄像头必须来自本地登记文件并按教师账号授权；媒体适配层不接收任意 URL。RTSP 经 FFmpeg 输出 JPEG，HTTP(S) 抓图直接适配，浏览器本地分析后上报教室级信号。原始画面不入库，学生投影不包含校园画面和观测明细。按设备互斥、课堂版本、授权、已发出帧版本和过期时间共同约束写入。详情见 campus-deployment.md。
