# AetherClass 智课云舱

面向课堂的实时反馈、课程资料问答与教学跟进系统。当前版本 0.3.0。

## 运行

要求 Node.js 22.13 或以上（推荐 24 LTS）（本轮验证 v24.18.0），无第三方 npm 依赖。

```powershell
cd "E:\系统设计\系统设计 (2)\系统设计\course-insight"
npm start
```

默认地址：[http://127.0.0.1:8000](http://127.0.0.1:8000)。端口被占用时，设置 `$env:PORT="8010"` 后重新运行。地址本身不会启动服务。

首次使用点击“注册新账号”，填写唯一账号、密码、姓名并选择身份。之后用账号密码登录。教师进入工作台创建课堂；学生注册独立账号，输入课堂码加入。同名用户不会共享身份，刷新或重新登录保留原账号。

账号由 SQLite 独立持久化，密码使用随机盐 + scrypt 哈希。每位教师拥有独立课堂、资料库、历史和屏幕通道，可同时开课。设置 `TEACHER_ACCESS_CODE` 可限制教师注册；未配置时允许自助注册教师账号。

## 本次新增

- 教师“课堂管理”：限时签到与名单、页面切后台次数/窗口失焦/后台时长、查看学生主动共享的屏幕、评论区开关/置顶/隐藏恢复。
- 学生签到、评论、共享/停止屏幕；结课自动停止采集，管理记录进入复盘与导出。
- [视觉验证实验室](http://127.0.0.1:8010/vision-lab.html)：本地真实视频回放、真实摄像头、区间标签、覆盖率/精确率/召回率/混淆矩阵、JSON 导出。
- 正式课堂本地视觉采样与网络上报分离：每次识别结束后约 500 ms 继续检测，网络约 4 秒上报。不可判定不再沿用旧自动举手或闭眼结果。

## 已集成能力

- 本地 MediaPipe 人脸、姿态举手、持续闭眼信号检测；JS/WASM/模型已随项目托管。
- 浏览器页面、窗口、空闲遥测与学生主动反馈，持续上报并实时同步。
- SSE 多端数据同步、可重连连接状态、独立标签页会话与刷新恢复。
- 教师投票、学生去重作答、屏幕图片帧中继、门禁模拟与教室过滤。
- 教师文本资料入库、切片检索、问答引用片段、历史问答保存。
- 可配置 OpenAI 兼容外部模型；未配置或失败时使用本地资料检索。
- 可解释规则学情报告，以及关联报告的教学回应、学生理解确认、教师结论。
- 过程采样曲线、结束快照、课堂归档、跨课历史和 Markdown 导出。

完整评估、统计口径、验证与优先改进方向见 [工程评估](docs/engineering-review.md)。

## 一堂课的数据闭环

1. 教师开设课堂，学生凭课堂码加入。
2. 学生自动信号、主动反馈、提问写入后端，教师端实时更新。
3. 教师分析课堂信号，向全体或指定学生发送教学回应。
4. 学生反馈“我已理解 / 仍需帮助”；教师记录跟进结论。
5. 教师结束课堂，冻结过程数据、问答、投票和干预记录。
6. 工作台查看历史复盘、导出记录，指导下一次教学。

## 数据存储与恢复

默认在线数据为 `backend/data/aether.sqlite`；通过 `DATA_DIR` 指定独立目录。服务采用单进程部署，多位教师可同时使用各自工作空间。

- accounts 表保存唯一账号及密码哈希；workspaces、live_classes、classroom_archives 均关联 owner_id。
- 课堂业务状态仍以每位教师一份 JSON 快照保存在 SQLite，事务更新课堂索引与归档；目前不适合多进程共享内存会话或大规模高频写入。
- 旧 `store.json` 原文件保留，其内容按校验和保全到 legacy_imports。旧姓名没有可信账号归属，不会自动向任何新注册账号开放历史；后续迁移必须由管理员明确指定归属。
- 新课只重置本教师当前课堂，保留自己的资料与历史。其他教师无法访问其归档、导出、SSE 或共享画面。
- 屏幕图片仅保留在内存，15 秒无新帧视为过期；学生停止、退出、转课或结课后不可继续查看。摄像头只上传计算结果。
- 会话在进程内保存，12 小时到期；重启需重新登录，但账号与课堂不丢失。
- 备份时先正常停止服务，再复制整个 DATA_DIR（包含 SQLite、WAL/SHM 若存在及旧 JSON）；不要运行中只复制主 sqlite 文件。

## 外部 AI 配置

后端通过环境变量读取配置，密钥不进入前端。可设置：

```powershell
$env:AI_API_URL="https://你的服务地址/v1/chat/completions"
$env:AI_API_KEY="你的密钥"
$env:AI_MODEL="你的模型名称"
$env:AI_PROVIDER_NAME="学习助手"
npm start
```

当前外部模型用于学生问答。教师学情报告明确使用 `rule-based-v1` 规则分析。提示词提供问题、召回资料及课堂聚合指标；具体教师和学生的原始图像不会发给模型。

## 局域网

```powershell
npm run start:lan
```

使用终端打印的真实局域网地址。多设备摄像头和屏幕共享通常需要 HTTPS；当前不是 WebRTC 音视频会议，屏幕约 0.8 秒更新一张 JPEG，没有系统音频。门口传感器按钮属于明确标注的模拟输入。

## 验证


本轮自动回归结果见 `docs/verification/account-tools-tests.txt`。测试使用随机端口和系统临时目录，不修改用户数据；外部 AI 使用本地模拟服务验证，未调用真实计费模型。浏览器已验证新账号注册、教师开课、学生加入、签到推送、评论提交/置顶/关闭和复盘；实验室三份模型初始化成功。真人视频准确率、真实屏幕采集与公网多人容量仍待设备验收；不要把接口构造数据当作识别准确率证据。详见 [真人视觉验收](docs/vision-validation.md)。

## 识别与人数边界

人脸、姿态和面部特征来自预训练 MediaPipe；专注、风险和持续闭眼提示是规则估计，不是自建数据集训练的专注模型。教师不进入学生统计；未采集状态显示等待，掉线不当作能力不足。

摄像头接入数按真实启用信号统计。门禁与在线成员取较大值估计在场人数，避免简单相加导致重复计数；该估计不等于身份对齐的物理人数真值。
