# Vibe Coding 关键迭代日志

## 第一次方向

最初项目是“课程资料智能问答与课堂实时反馈系统”，核心能力是 RAG 问答和课堂反馈。

## 问题判断

这个方向虽然能跑，但亮点不够强。它更像一个课程助手，而不是一个能在满分答辩中留下印象的系统。

## 方向升级

根据评分标准，项目升级为“智课云舱：AI 驱动的线上课堂学情监测系统”。

升级理由：

- 摄像头和传感器提供真实数据来源。
- 实时流让教师端马上看到变化。
- AI 学情分析让结果参与教学决策。
- RAG 知识库让问答有依据。
- 轻量预测模型让系统有分析能力，而不是只展示数据。

## 当前实现

- 后端重构为课堂数据中枢。
- 前端重做为教师驾驶舱。
- 支持学生端摄像头调用。
- 支持门口传感器事件。
- 支持 SSE 实时更新。
- 支持 RAG 资料问答。
- 支持 AI 学情报告。
- 支持低参与风险预测。

## 备用方案

摄像头权限或硬件不可用时，可以通过“模拟疑惑状态”和“传感器进入 / 离开”完成完整演示，不影响核心闭环展示。
